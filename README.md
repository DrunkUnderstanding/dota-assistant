# Dota 2 选人助手（自用）

天梯全英雄选择的选人阶段，自动识别屏幕上双方已选的英雄，告诉你**这个位置拿谁**、为什么。
推荐显示在游戏画面上的半透明叠加层里。（语音播报暂时默认关闭，`config.toml` 写 `voice = true` 能打开。）

- 推荐依据：最近两周超凡入圣～冠绝一世的天梯对局（克制、配合、分位置强度）＋ 你自己最近 300 局天梯的英雄与战绩
- 只读屏幕截图和 Valve 官方的 Game State Integration（GSI），**不读游戏内存、不注入、不代替操作**

开发进度、架构和下一步见 [docs/HANDOFF.md](docs/HANDOFF.md)。

---

## 免安装版：解压后双击「Dota选人助手.exe」

拿到的是 `Dota选人助手-<版本>.zip` 的话，不用装 Python 和 Node.js：解压到一个**有写权限**的文件夹（别放 Program Files），
双击 `Dota选人助手.exe`。第一次打开控制面板会弹出「设置」，填 Steam 好友代码、STRATZ token（可选）、AI 打法用哪家；
以后在控制面板右上角「设置」里改。数据缓存、日志、截图都放在这个文件夹里。

AI 打法（选完人后写这局怎么打）有三种来源，在「设置」里选：
- **Claude Code 订阅**：这台电脑装了 Claude Code 并登录过就能用，不另外花钱
- **Anthropic API Key**：填自己的 Key，按用量付费
- **OpenAI 兼容接口**：DeepSeek、通义千问、Kimi 等，填接口地址、Key、模型名（不是 Claude，效果没验证过）

自己打包：`pip install pyinstaller anthropic`，`electron/` 下 `npm install` 过一次，然后 `python packaging/build.py`，
产物在 `build/`。打包不会带上本机的 `config.toml`（脚本最后会扫一遍确认密钥没混进去）。

## 从源码运行：双击「启动助手.bat」

先装两样东西（各装一次）：
- **Python 3.11+**：[python.org](https://www.python.org/downloads/)，安装时勾选 Add to PATH
- **Node.js LTS**：[nodejs.org](https://nodejs.org)（界面用）

然后每次打游戏前**双击 `启动助手.bat`**。它会自动：
1. 第一次运行时生成 `config.toml`，控制面板弹出「设置」让你填 Steam 好友代码、STRATZ token、AI 来源
2. 第一次运行时安装依赖和界面组件
3. 找到 Dota 安装目录，写好 GSI 配置
4. 数据旧了自动更新（全量 3 天一次，个人数据半天一次）
5. 打开控制面板和叠加层

只有一件事要你手动做一次：Steam 库里右键 Dota 2 → 属性 → 启动选项，加上 `-gamestateintegration`；
Dota 设置里显示模式改「无边框窗口」，社交里打开「公开比赛数据」。

选人阶段的 GSI 推送会自动存到 `shots/gsi/`，用来确认 GSI 能不能直接给出双方阵容。

下面是各步骤的手动做法和细节，出问题时再看。

## 一、安装（游戏电脑上做一次）

需要 **Python 3.11 或更高**（[python.org](https://www.python.org/downloads/) 安装时勾选 Add to PATH）
和 **Node.js 18 或更高**（[nodejs.org](https://nodejs.org/)，界面用 Electron 画）。

```
cd dota-assistant
pip install -r requirements.txt
cd electron
npm install          # 下载 Electron（约 100MB）；国内慢的话先 set ELECTRON_MIRROR=https://npmmirror.com/mirrors/electron/
```

`config.toml` 是个人配置（好友代码、STRATZ token 等），不进 git。拷整个文件夹过来的话它已经在了；
新环境就 `copy config.example.toml config.toml` 再改。

## 二、拉数据

```
python -m dota_assistant update            # 全部：英雄表、头像、分位置数据、个人数据、克制 / 配合，4~5 分钟
python -m dota_assistant update --player   # 只刷新你自己的段位和近期英雄，几秒
```

建议每天开打前跑一次 `update`，大版本更新后一定要跑。`data/` 文件夹可以直接从别的电脑拷过来。

## 三、让游戏配合

1. **无边框窗口**：Dota 设置 → 视频 → 显示模式选「无边框窗口」。独占全屏下叠加层盖不上去，截图也可能是黑的。
2. **GSI**（告诉助手你在天辉还是夜魇、是不是选人阶段、你选了谁）：
   ```
   python -m dota_assistant gsi-install "C:\Program Files (x86)\Steam\steamapps\common\dota 2 beta"
   ```
   然后在 Steam → Dota 2 → 属性 → 启动选项 加上 `-gamestateintegration`，重启游戏。
   不装 GSI 也能用，只是要在控制面板里手动选「我在天辉 / 夜魇」，打游戏时叠加层也不会自动隐藏。
3. **公开比赛数据**：Dota 设置 → 社交 → 打开「公开比赛数据」，否则拉不到你的近期英雄。

## 四、校准（第一次用、换分辨率或游戏 UI 改版后做）

1. 进一局天梯，**选人阶段双方都选了几个英雄时**按 `F10`（要先 `run` 起来），或者用 Steam 截图键 F12，存一张**原始分辨率**的全屏截图。
2. 在截图上框格子：
   ```
   python -m dota_assistant calibrate shots\20261021-203000.png
   ```
   依次框：天辉第 1 个、第 5 个英雄头像，夜魇第 1 个、第 5 个英雄头像（中间的自动等距补齐），
   然后可选地框第一个和最后一个禁用头像（按 `S` 跳过）。**只框头像图本身，不要带名字和边框。**
   `Backspace` 撤销，`Esc` 放弃。结果存到 `calibration.json`。
3. 检查效果：
   ```
   python -m dota_assistant recognize shots\20261021-203000.png
   ```
   会打印每个格子的识别结果和相似度，并生成一张 `xxx_识别.png` 标注图（绿框 = 认出，红框 = 当空位）。

## 五、教它认得更准（强烈建议做几局）

初始模板是官方网站的英雄横版头像，和游戏里的样子不完全一样。用真实截图「教」几次就会准很多：

- **实时纠正**：选人时如果控制面板格子里的名字不对，直接改成正确的（空位就清空），再点「记住这次识别」。
- **批量纠正**：把攒下的截图一起过一遍：
  ```
  python -m dota_assistant label shots\*.png
  ```
  每个格子回车 = 认同，输入英雄名 = 纠正，`0` = 空位，`-` = 跳过。

学到的模板存在 `templates/<英雄 id>/`（`templates/0/` 是空位），越用越准，可以跟着项目一起拷走。

## 六、开打

```
python -m dota_assistant run
```

会弹出**控制面板**，游戏画面上出现**叠加层**（只有推荐英雄卡片和右上角按钮能点，其余地方鼠标点得穿，不影响操作）。关掉控制面板就退出。

- 叠加层是一张卡片：顶上是位置和阵营，下面双方已选的头像，然后是推荐英雄（头像、胜率、胜率条，
  理由按颜色分：绿 = 克谁、蓝 = 配谁、红 = 怕谁、橙 = 易被反制、紫 = 你自己的战绩），最下面是威胁提醒。
- **对面分路**：对面选了人，卡片上就按「每个英雄在这个分段最常打的位置」猜他走哪路，上 / 中 / 下三行，你这路描金边、写着你的同路队友。
  头像右下角是猜的位置，带「?」、半透明的是没把握的（大概五五开）。实测（3000 场超凡～冠绝）：五人选完时单人位置猜对约 80%，
  你这路的对手是谁完全猜对：中单 81%、三 / 四号位 68%、一 / 五号位 62%。**你选好英雄以后**，下面接着「你这路怎么打」：
  对面的控制和冷却、谁的持续施法能被你打断、近战 / 远程和射程差、对面的跑路技能、你和队友的控制配合、对面带控制的大招。每条悬停能看官方原文。
- **剩余位置**：队友选了人以后，阵容下面列出我方五个位置：队友占了的显示队友头像（选人界面认出的位置优先，其余按常打位置猜，带「?」的是没把握），
  空着的位置后面是「你打这个位置」的前两个推荐和胜率，胜率最高的位置描金边标「推荐」。**点空位置就切过去按那个位置推荐**（和控制面板的位置按钮一样）；
  队友占了你当前的位置时那一行标红。适合加速 / 普通匹配这种没有位置字样、要自己挑位置的局。
  **你选好英雄以后这块还在**，一直留到进游戏：你那格显示你的英雄，空位置后面换成**给队友的推荐**（算上和你的配合），可以照着跟队友说。
- 推荐英雄下面的小字是**机制上为什么**：✓ = 它的技能克对面某个技能（例如克敌机先 → 对面闪避无效），✗ = 对面某个技能克它；鼠标停在上面能看到官方原文。
- **点一下推荐英雄**（叠加层或控制面板右边的预览都行）：弹出「如果选它」卡片，数据页是分路和对线（对线数据 + 你这路怎么打）、起手装、强势期、出装（核心装顺序 + ★针对这局阵容的装备，悬停看原文）、对面要防；
  AI 写完（约 30~60 秒）自动翻到打法页：前 / 中 / 后期怎么打、对线劣势怎么办。点标签或 F6 翻页，× 回到推荐。AI 打法要装 Claude Code 并登录。
- 控制面板右边是叠加层的实时预览。
- **调位置**：点叠加层右上角的🔒（或按 F7）解锁，锁变成打开的金色🔓、卡片出现金色虚线框，按住卡片拖到想要的地方，
  再点一下锁（或按 F7）固定，恢复鼠标穿透。解锁时按住卡片**右边缘的金色拉手**左右拖可以改宽度，宽到 640 以上内容自动分左右两栏；
  内容比屏幕还长时整张卡片会自动等比缩小到放得下。固定时只有右上角的锁和 × 能点，其余地方照样点穿。
- **关闭**：点叠加层右上角的 ×（或按 F8）。弹着局内提醒时只关这条提醒；否则整个叠加层收起，按 F8 或控制面板「显示叠加层」重新打开。位置记在 `data/overlay.json`，下次启动沿用。
- **回家买**：对局里每次死亡，卡片上说下一件该买什么、还差多少钱（「下一件：黑皇杖（针对），还差 850 金；之后 蝴蝶、白银之锋」）。
  顺序 = 同分段这个英雄这个位置的核心装 + 针对这局阵容的装备（控制多 → 黑皇杖提前，指向性大招多 → 林肯 / 清莲，被动怕破坏 → 白银之锋……，只推你这个英雄会出的）。
  觉得哪件不用出，写进 `knowledge/rules.toml`（英雄 + 物品）。
- **死亡复盘**：对局里每次死亡弹一张「死亡复盘」卡片，说刚才是怎么死的：几秒内从多少血到死（被控死 / 瞬间打爆 / 残血拖太久）、
  被眩晕 / 沉默了多久、保命装备和技能（黑皇杖、跳刀、大招…）用没用、死在哪、掉了多少钱、买活够不够；下面接着列这局还缺什么。
  复活后自动收起。只根据 GSI 里你自己英雄的状态推断，看不到谁杀的你。要重新写一次 GSI 配置（`start` / 启动助手会自动写，只用 `run` 的话重跑 `gsi-install`）并**重开 Dota**。
  每次死亡前 20 秒左右的原始推送存在 `shots/deaths/`，觉得说得不对就把那份文件发给开发者。
- 没装 Electron 时：`run --browser` 用浏览器打开（叠加层只是预览，盖不到游戏上）。

| 热键 | 作用 |
|---|---|
| F7 | 解锁叠加层（可以拖动）/ 固定位置 |
| F8 | 显示 / 隐藏叠加层 |
| F9 | 立即重新识别，并把当前推荐再念一遍 |
| F10 | 保存一张全屏截图到 `shots/`（攒校准 / 学习素材） |
| F6 | 再看一次本局要点；选人时翻页 |

热键在控制面板「设置」（右上角齿轮，或直接点顶栏的快捷键）里改，保存后马上生效。

控制面板：

- **位置**：这局你打几号位（默认取 `config.toml` 的 `position`，天梯排队选的位置记得改）
- **阵营**：默认跟 GSI；没装 GSI 时手动选
- **自动识别 / 手动输入**：识别不靠谱时切到手动，自己在 10 个格子里打英雄名（支持简称：PA、冰女、小牛……，
  打字时下拉框会列出带头像的候选，↑↓ 选、回车确认并跳到下一格）
- 10 个格子就是「当前局面」：识别结果会填进来，你也可以随时改；正在编辑的格子不会被识别覆盖
- 格子里灰色的「? 某某」= 最像某某但相似度不够，当空位处理；头像右上角的数字是相似度。名字打错的格子会标红

叠加层的位置、宽度、透明度、热键、语速、识别阈值都在 `config.toml` 里调（字段说明见 `config.example.toml`）。

```

python -m dota_assistant suggest --enemy PA,斧王,冰女,莱恩,影魔 --pos 1 --me 卓尔 --side radiant   # 选好了：看对面分路 + 你这路怎么打

python -m dota_assistant say 测试一下语音

python -m dota_assistant coach-sim 9054096051   # 拿一局录像重放，看「这局缺什么」的提醒当时会怎么说
python -m dota_assistant brief-sim 9054096051  # 拿一局录像看选完人时「本局要点」卡片会写什么（加 --ai 同时看 AI 打法）
```

知识库来自 Valve 官方数据，`update` 时版本号变了会自动重拉。你确认过的经验判断写在 `knowledge/rules.toml`（会跟着项目走）。

## 推荐怎么算

在对数几率空间相加，最后换回胜率作为「指数」：

- **英雄自身强度**：统计期内胜率，按 STRATZ 分位置胜率修正（同一个英雄打不同位置强弱不同）
- **克制**：对上每个敌方英雄的实际胜率减去按双方强度推算的期望；样本少的收缩回期望值
- **配合**：和每个队友同队的胜率，同样扣期望（权重 0.7，收缩更强）
- **熟练度**：你在**这个位置**最近用过 3 局以上算「你的英雄」，打满 20 局加约 2 个百分点
- **个人表现**：你用这个英雄比同分段平均好还是差（收缩很狠）
- **手写英雄池** `pool`：加约 1 个百分点，不受位置筛选限制

输出分「你的英雄」（3 个）和「其他选择」（2 个）。括号里是近似胜率百分点，例如「克 幻影长矛手(+5.5%)」。
位置筛选：该分段这个英雄至少 10% 的局打这个位置；你自己在这个位置打过的英雄不受限。

## 常见问题

- **叠加层看不到**：游戏不是无边框窗口；或者按过 F8 隐藏了；或者 GSI 显示已在游戏中（非选人阶段会自动隐藏）。
- **识别全是空位**：没校准 / 校准的截图分辨率和现在不同宽高比；用 `recognize` 看相似度，必要时调低 `match_threshold`，最好用「记住这次识别」教几次。
- **热键没反应**：控制面板状态栏会写哪个热键注册失败（被别的软件占了），在控制面板「设置」里换一个。
- **没声音**：语音默认关着，`config.toml` 里写 `voice = true`；或系统没有中文语音包（设置 → 时间和语言 → 语音 → 添加语音「中文（简体）」）。
- **端口 3000 被占用**：改 `config.toml` 的 `gsi_port`，然后重新 `gsi-install`。
- **出了问题 / 想反馈**：控制面板点「打开日志」（或 `python -m dota_assistant logs`），把最新的 `.log` 文件发给开发者。
  每次启动一个文件，只留最近 30 个；里面不会有 STRATZ token。排查识别问题时可以在 `config.toml` 里写 `log_level = "DEBUG"`。
