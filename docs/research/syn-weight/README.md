# 配合权重 W_SYN 取 0.5 还是 1.0（2026-11-09）

起因：同行 gg-go-next 的选人打分是「克制合计 + 0.5 × 配合合计」，玩家要「试试 0.5」。

做法（`scripts/syn_weight.py`）：和 `python -m dota_assistant backtest` 同一套样本（统计截止点之后的新对局，STRATZ 取选人顺序和位置）和同一套打分，只换配合系数，同一批对局配对比较，按对局重抽样 1000 次给 95% 区间。

| | 区分度（全部） | 区分度（有队友时） | 阵容准确率 | 对数损失 |
|---|---|---|---|---|
| W_SYN = 0.5 | 0.0667 | 0.0677 | 58.47% | 0.66968 |
| W_SYN = 1.0 | 0.0649 | 0.0662 | 58.03% | 0.67069 |
| 0.5 − 1.0 | +0.0018 [−0.0004, +0.0041] | +0.0015 [−0.0012, +0.0042] | | −0.0010 [−0.0023, +0.0003] |

3000 场样本外（match_id > 9077043240）。三项方向都是 0.5 略好，但区间都含 0，属于噪声范围；第 45 节逐项相加拟合的配合系数 0.75 也在这个方向。按玩家要求改成 0.5（`domain/engine.py` 的 `W_SYN`，domain/NOTES 第 73 节）。

```
python docs/research/syn-weight/scripts/syn_weight.py 3000   # 要 STRATZ token；样本缓存在 data/backtest_matches.json
```
