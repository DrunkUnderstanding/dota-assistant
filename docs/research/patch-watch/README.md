# 7.42 英雄胜率监控

上线后每 3 小时拉一次 STRATZ 分小时英雄胜率，重算传奇以上的估计胜率，写成单文件网页 `data/mockups/7.42-英雄胜率走势.html`（双击就能打开，开着的页面 20 分钟自己刷新一次）。

- `watch.py`：拉数据、攒历史、算排名、出网页。只读 STRATZ，不改项目代码和 `data/` 里别的东西。
- `page.html`：网页模板，`watch.py` 往里填英雄头像和数据。
- 历史和日志：`data/patch_watch/`（`hours.json` 是攒下来的分小时数据，`watch.log` 是每次运行的记录）。

## 算法

- 上线时间点：2026-11-18 21:00 UTC（北京时间 11-19 05:00）。看的是重做英雄的出场率在哪个小时翻倍，没用更新日志的发布时间。
- STRATZ 的 `heroStats.winHour` 只返回最近约 30 个小时，所以要每次拉下来攒着。同一个小时只在新拉的场次更多时才替换（窗口最前面那个小时只拉到一部分，最后那个小时还没入库完）。
- 网页上能切换段位：「传奇以上」（传奇 / 万古 / 超凡 / 冠绝）和「超凡以上」（超凡 / 冠绝），默认超凡以上，记住上次选的。超凡以上样本约是传奇以上的五分之一，误差大约翻倍。
- 估计胜率和「版本解读」用同一个算法：先验 = 上线前本段位胜率 + 全分段涨跌（按样本量往 0 收缩），再用上线后本段位的累计实测更新。每 3 小时取一个点，每次都从头重算，所以前面的点也会随数据补全微调。
- STRATZ 的分小时数据要晚 1 个多小时才入库，所以在每个 3 小时整点（北京时间 2/5/8/11/14/17/20/23 点）过 1 小时 40 分时跑。

## 运行

```
python -X utf8 docs/research/patch-watch/watch.py            # 跑一次
python -X utf8 docs/research/patch-watch/watch.py --no-fetch # 不拉数据，只用攒下的重画网页
pythonw -X utf8 docs/research/patch-watch/watch.py --loop    # 常驻，每 3 小时一次，上线满两周自己退出
```

这台电脑上建 Windows 计划任务会提示「拒绝访问」，所以改成常驻进程（`--loop`，用锁文件保证只有一个在跑）。**重启电脑后要再运行一次最后那条命令。** 要停的话，在任务管理器里结束命令行带 `watch.py --loop` 的 `pythonw.exe`。
