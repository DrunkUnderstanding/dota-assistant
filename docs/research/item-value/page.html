装备价值换算

  • 怎么换算：每项属性的单价 = 只加这一项、最便宜的基础装（例如生命按毛毛帽算 2 金 / 点），见下面「单价」。一件装备的价值 = 它面板上每项属性 × 单价，加起来。
  • 百分比 = 换算价值 ÷ 售价。100% = 和买对应基础装一样划算；高于 100% = 合成以后属性更便宜。
  • 看谁用：力 / 敏 / 智属性按游戏内说明换成生命、攻速、护甲、魔法等再算钱；配上主属性每点再 +1 攻击，全才英雄每点 +0.45 攻击。「面板」= 不分英雄，属性一律按力量手套 46.7 金 / 点。
  • 只算面板上的固定属性：主动技能、光环、触发效果都不算，所以跳刀、黑皇杖这类是 0% 或很低——低不等于不值得买，说明你买的主要是它的技能。几个常用的主动（魔瓶、魔杖、灵魂之戒）在说明里单独折了钱。
