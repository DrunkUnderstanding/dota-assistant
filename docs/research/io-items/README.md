# 艾欧对上难打的阵容，出什么装更好赢 / 死得更少（2026-11-06）

一次性研究，不进产品代码。接着 `domain/NOTES-ingame.md` 第 33 节（剑圣对幻象测不出针对装），这次换成玩家选的艾欧，样本更大，并且控制了买装那一刻的经济差，另外加了「之后 10 分钟死几次」这个更直接的指标。玩家的打算是先拿艾欧验证，有效再扩到别的英雄。

## 数据

- 7.41f（2026-09-15 起）超凡～冠绝，天梯全英雄选择，时长 ≥ 15 分钟。OpenDota explorer 每 50 万个 match_id 取一块、隔一块跳过，得到 81378 局艾欧（大约是全部的一半）。
- 按「对面阵容难不难打」分层抽 4 万局，从 STRATZ 抓到 38400 局详情（中途撞上 STRATZ 限速，剩下的没抓）。每局取艾欧的出装时间、每次死亡和凶手，以及全场 10 个人每分钟的经济。
- 有出装记录的局里，辅助（4 / 5 号位）18988 局，核心（1 / 2 / 3 号位）11344 局，两种分开算。

## 方法（`scripts/c_an.py`）

- **难打**：先算艾欧对每个英雄的实际胜率（收缩过；只用**没抓 STRATZ 的那一半**对局来算，不和分析用的局重叠），每局把对面 5 个人的值加起来，最难打的 1/3 算「难打组」。
  - 一开始用的是引擎的「克制」值（扣掉双方强度之后的部分），结果难打组和其余的胜率一样（52.0% 对 52.1%）。原因是这个值会把影魔这种本身就弱的英雄也算进来：艾欧对影魔的实际胜率是 57%，只是比按两边强度推算的低。玩家问的是「对上胜率低的英雄」，所以改用实际胜率。
  - 改完以后差距拉开了：辅助难打组 46.5%、其余 55.0%；核心 43.1% 对 50.3%。实际胜率最低的对手：赏金猎人 -7.4、谜团 -5.5、斯温 -4.3、克林克兹 -3.8、远古冰魄 -3.6、破晓辰星 -3.5、军团指挥官 -3.4（百分点）。
- **候选装备事先按规则定**：价格 ≥ 800、不是消耗品，25 分钟前有 ≥ 4% 的艾欧出过。辅助是梅肯斯姆、圣洁吊坠、灵魂之戒、微光披风、影之灵龛、阿哈利姆神杖、奥术鞋；核心是阿哈利姆神杖、黑皇杖、支配头盔、灵魂之戒、希瓦的守护、漩涡、坚韧球。
- **比较**：分别取打到 15 / 20 / 25 分钟的局，对每件装备做线性回归（稳健标准误）：结果 = 出了 + 难打 + 出了×难打 + 当时全队经济差（分 10 档，再加线性项）+ 艾欧自己的经济 + 这之前死了几次 + 位置 + 阵营。看三个结果：胜率；之后 10 分钟内的死亡数；之后 10 分钟内被「对艾欧胜率低 ≥ 约 1.5 个百分点的英雄」杀死的次数。
- 每件装备给两个数：**难打组里出了的效果**（出了 + 出了×难打），和**针对性**（出了×难打，也就是同一件装备在难打局里比在一般局里多出来的部分）。
- **多重比较**：辅助一共比了 114 次、核心 98 次，光靠运气每 20 次就会有 1 次看起来显著，所以按 Bonferroni 校正，|z| 要超过约 3.5 才算数。

## 结果

**辅助（18988 局）**：没有一件装备有显著的针对性。

| 装备 | 难打组里出了的效果（胜率，15 / 20 / 25 分钟） | 针对性 | 之后 10 分钟死亡 |
|---|---|---|---|
| 灵魂之戒 | **+4.3 ±2.1 / +3.3 ±1.9 / +3.0 ±1.9** | +0.9 / +1.1 / +1.4（都不显著） | 少 0.10～0.14 次 |
| 梅肯斯姆 | 0.0 / -0.8 / -0.7 | +1.7 / +2.3 / +1.5 | 没变化 |
| 圣洁吊坠 | +0.2 / +0.4 / +0.8 | +0.3 / -1.2 / +0.6 | 没变化；被克制英雄杀的次数少 0.06 左右（校正后不显著） |
| 影之灵龛 | -2.4 / -2.2 / -2.6 | -1.1 / -1.4 / -1.6 | 没变化 |
| 微光披风 | 20 分钟只有 90 局，25 分钟 +0.9 | 不显著 | 20 分钟前出的少死 0.37 次，样本太小 |

- 校正后唯一显著的是「灵魂之戒，难打组，15 分钟，胜率 +4.3」（z = 4.0）。不过它的针对性是 +0.9 ±2.6，**一般局里也差不多一样好**，所以不是对付难打对手的装备，而是「早出灵魂之戒的艾欧整体打得更好」。这里分不清是装备本身的作用，还是出灵魂之戒的玩家打法不同（比如更会玩、更主动），只能说出了的局确实更好。

**核心（11344 局）**：没有一件装备在难打局里让胜率显著变高。

- 黑皇杖（20 分钟前出）、希瓦的守护（25 分钟前出）：被克制英雄杀死的次数显著少了（针对性分别是 -0.15、-0.19，z = 4.1、5.1），但**总死亡数没少**（针对性约 0），胜率也没变好（黑皇杖 25 分钟 -5.0 ±3.1，希瓦 +1.8 ±4.9）。只是换了个英雄杀你。另外难打局里本来就有更多这类英雄，所以这个数字有一部分是比例本身带来的，不能当成针对装的证据。
- 支配头盔（15 分钟前出）：难打局里之后少死 0.23 次（z = 4.0），但针对性约 0（一般局里也一样），胜率没变化。

## 结论

1. **用艾欧验证的结果：「对上难打的阵容出某件针对装就更好赢」，在 7.41f 约 1.9 万局辅助艾欧、1.1 万局核心艾欧里都找不到支持。** 样本比第 33 节大了好几倍，区间缩到 ±2 个百分点左右，所以真有效果的话，也应该小于 2～3 个百分点。
2. 能看出来的都是"在所有局里都好"的装备或打法（辅助早出灵魂之戒），而不是针对某类对手的装备。
3. 所以这个方法扩到别的英雄，大概率也是同样的结果。如果还要继续，更有希望的方向是：改成具体到「某个英雄的某个技能 ↔ 某件装备」（比如对面有斯温，就看出没出能解斯温锤子的装备），而不是「一类难打的英雄」；或者只在对面真的造成威胁的局里比较（比如对面核心 20 分钟时经济领先）。

## 第二个英雄：拉席克（2026-11-06，`--target 52`）

玩家看完艾欧的结果后问「换拉席克这个英雄呢」，方法完全一样。

- **数据**：7.41f 超凡～冠绝 45070 局拉席克；难打组全部 15023 局加上其余的 2 万局，一共要抓 35023 局，抓到 30000 局时撞上 STRATZ 每小时的上限（免费 token 每小时 1500 次、每天 15000 次请求，一次 20 局），剩下的没再等。核心（1 / 2 / 3 号位，其中 2 号位 74%）有出装记录的 21498 局；辅助只有 1719 局，太少，不看。
- **难打**：实际胜率最低的对手是殁境神蚀者 -6.7、赏金猎人 -5.5、维萨吉 -4.7、狼人 -4.2、亚巴顿 -4.2、帕克 -3.6、冥魂大帝 -3.4（百分点）。难打组胜率 48.2%，其余 55.6%。
- **候选装备** 17 件，比了 280 次，校正后 |z| 要超过 3.75。

**胜率和总死亡数：没有一件装备过校正。** 最接近的几个：

| 装备 | 难打组里出了的效果 | 针对性 | 之后 10 分钟总死亡（难打组） |
|---|---|---|---|
| 黑皇杖（25 分钟前） | -1.0 ±2.3 | **+3.4 ±2.8**（z ≈ 2.4） | -0.16 ±0.09 |
| Eul 的神圣法杖（15 分钟前） | +6.2 ±6.1 | +11.5 ±7.6（z ≈ 3.0，只有 218 局） | +0.06 ±0.18 |
| 夜叉 / 慧夜对剑（25 分钟前） | +0.9 / +0.6 | +1.5 / +1.3 | -0.10 / -0.09 ±0.09 |
| 振魂石 / 血精石（25 分钟前） | +2.6 / +2.1 | +0.4 / +0.2 | +0.03 / +0.05 |

**「被克制英雄杀的次数」这个指标不可靠**：第一遍几乎每件装备都「显著」（过校正的 22 个全是这个指标），加上「对面有几个克制英雄」做控制以后还是 20 个。但同样这几件装备，总死亡数基本没变。比如振魂石（25 分钟前出）被克制英雄杀的次数 -0.14（z = 4.8），总死亡数却是 +0.03。原因有两个：
1. **只是换了凶手**：击杀算在最后一击的人头上，肉一点的拉席克不容易被对面辅助的爆发（赏金、帕克、冰魄这些）带走，改成被对面核心杀，总数不变。
2. **刻度问题**：一般局里对面几乎没有这类英雄，这个数本来就接近 0；难打局里本来就高，同样按比例减少，在难打局里绝对值就大，差中差看起来就「显著」。

艾欧那边核心组的黑皇杖 / 希瓦的守护也是同样的情况。**以后看结果只认胜率和总死亡数**，这个指标留着作参考。

**结论**：和艾欧一样，按「对上一类难打的英雄」测，没有哪件针对装能让拉席克明显更好赢或死得更少。唯一三个指标方向一致的是 **25 分钟前出黑皇杖**：针对性 +3.4、难打组总死亡 -0.16，但都没过校正。要确认它，可以只测这一个假设（这样就不用做多重比较校正），换一批没用过的对局再测一次：之前拉编号是隔一块取一块，另一半编号区间完全没碰过，大约还有 4.5 万局拉席克。
