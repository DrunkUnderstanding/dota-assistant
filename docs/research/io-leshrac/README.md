# 精灵老鹿：艾欧 + 拉席克组合研究（2026-11-04）

一次性研究，不进产品代码。数据：冠绝 / 超凡、7.41f、近 14 天天梯全英雄选择（OpenDota 统计 + STRATZ 已解析对局）。

## 结论

**强度**：两人同队 5466 局，胜率 63.4%。按两人各自强度推算，期望胜率是 54.9%，这对多出 8.5 个百分点，是艾欧所有队友里配合最好的。

**主流打法**：拉席克 1 号位 + 艾欧 5 号位，两人一起走优势路。能确定位置的 227 局里有 177 局是这样，胜率 63%。下面的数字都按这 177 局算。

**节奏（中位时间）**

| 时间 | 大概率在干什么 |
|---|---|
| 0~6 分钟 | 双人优势路对线，约 80% 时间贴在一起，线上一直在打架（前 10 分钟两人各死约 1.5 次）。奥术鞋之前基本不推塔。拉席克补刀比一般 1 号位多：5 分钟 23 刀，一般是 17 刀。 |
| 6~11 分钟 | 6.0 分钟奥术鞋到手后边打边推。拉席克 8.7、艾欧 9.3 分钟到 6 级，**10.8 分钟第一次降临**。对面全图第一座塔约 11 分钟倒。 |
| 11~15 分钟 | **11.3 分钟慧光**到手，推塔伤害翻倍。拉席克单推优势路上对面那座一塔（中位 14.4 分钟），开始刷自家主野区。看到机会就降临去中路或劣势路。 |
| 15~20 分钟 | 组合最强的一段：降临后 25 秒内我方有击杀的比例最高，72%。对面三座一塔基本都倒了，我方的中路和优势路一塔也常丢，本质是换塔。 |
| 20~30 分钟 | 21 分钟纷争面纱，25 分钟黑皇杖（赢的局 23.8 分钟、输的局 27.3 分钟）。赢的局对面二塔 25~26 分钟倒，三条路的二塔主要是拉席克推的。 |
| 30~35 分钟 | 上高地，最先、也最常推的是中路高地塔。赢的局基地中位 33.9 分钟倒。 |
| 35 分钟以后 | 降临后阵亡反而比击杀多，45 分钟以上的局胜率只有 46%。 |

**出装**

- **拉席克**：铁树枝干、仙灵之火、魔棒出门 → 3.3 分钟王者之戒 → 6.0 分钟奥术鞋 → 11.3 分钟慧光 → 二选一：14 分钟慧夜对剑或 17 分钟散慧对剑 → 梅肯斯姆，17 分钟合成卫士胫甲 → 21 分钟纷争面纱 → 25 分钟黑皇杖 → 26.5 分钟血精石 → 28 分钟希瓦的守护 → 32.6 分钟阿哈利姆神杖。
- **艾欧**：树之祭祀、血腥榴弹、岗哨守卫出门 → 6.2 分钟魔杖 → 7.6 分钟灵魂之戒 → 18 分钟圣洁吊坠 → 27 分钟微光披风。艾欧几乎不买鞋。

**对线**：优势 43%（其中碾压 11%）、均势 27%、劣势 31%。不管队友是谁，拉席克打 1 号位时是优势 43% / 均势 29% / 劣势 28%，几乎一样，说明这对的胜率主要不是对线赢出来的。均势的局胜率 68%，劣势的局还有 47%。

**天辉 / 夜魇**（2026-11-04 补，`scripts/z_side.py`；样本小，只看方向）：

| | 天辉 | 夜魇 |
|---|---|---|
| 两人同队所有位置（OpenDota 1122 局） | 589 局，63.3% | 533 局，60.0% |
| 主流打法 177 局 | 94 局，**66.0%** | 83 局，60.2% |
| 时长中位 | **33.7 分钟** | 38.0 分钟 |
| 对线 优 / 均 / 劣 | **49%** / 20% / 31% | 36% / 34% / 30% |
| 对线劣势的局胜率 | 59% | **32%** |
| 优势路上对面那座一塔倒（中位） | **13.0 分钟** | 16.1 分钟 |
| 拖过 40 分钟的胜率 | 33~40%（27 局） | 47~57%（31 局） |

奥术鞋、慧光、黑皇杖、第一次降临两边几乎一样（6.0 / 11.3 / 25 / 10.5~10.9 分钟）。天辉更快：对线赢得多、一塔早推 3 分钟、比赛短 4 分钟，但拖到 40 分钟以后掉得更狠。夜魇对线赢得少、均势多，**对线一输就很难翻**。两边差 3~6 个百分点，和 Dota 本身天辉略占优（引擎里 `RADIANT_EDGE`）的幅度差不多，不一定是这对组合特有的。

**推塔**：对面的建筑基本是拉席克推。我方英雄打对面建筑的伤害里，拉席克在优势路一塔占 80%，在二塔、高地占 60~67%，其中六到八成是技能伤害（恶魔敕令「对敌方单位和建筑造成纯粹伤害」）。艾欧只占 4~10%。优势路上对面那座一塔 18 分钟前倒的局胜率 71~86%，18 分钟后才倒只有 54%。

**难打的对面**：按克制数据，美杜莎、赏金猎人、远古冰魄、斯拉达、昆卡、圣堂刺客、不朽尸王克这对最狠。远古冰魄的冰晶爆轰会让目标「无法恢复生命值」，正好掐掉羁绊 / 过载的回血。

## 出装细看（2026-11-09，`scripts/w_items.py`，第 70 节）

上面的出装只有 177 局。这次复用第 68 节针对装研究抓的 STRATZ 对局（7.41f 超凡～冠绝，那两批按对面难不难打分层抽样，难打局约占一半），挑两人同队、拉席克 1 号位 + 艾欧 5 号位的：拉席克 3227 局（胜率 65.3%）、艾欧 2322 局（64.3%），时长中位 35.6 分钟。输出存在 `data/research/io-items/pair_items_15.txt`。

「出了 vs 没出」的原始胜率差全是 +10～+25（领先才买得起），**只看按当时全队经济差分 5 档调整后的数**，而且仍有「什么局面才买」的偏差，只当参考。

- **拉席克**：出门 铁树枝干 + 仙灵之火 + 魔棒，再配圆环 + 树之祭祀（22%）或直接魔杖卷轴（21%）→ 2.4 分空灵挂件（45%）、3.3 分王者之戒（99%）→ 6.1 分奥术鞋 → 11.5 分慧光 → 第四件夜叉（慧夜对剑 59%，14.5 分）或散华（散慧对剑 36%，17.8 分）；13.6 分梅肯斯姆 → 16.5 分卫士胫甲（62%，比同位置全部局多 8 个百分点）或圣化护服（33%）→ 19 分纷争面纱 → 23 分振魂石 / 血精石 → 25 分黑皇杖 / 27.6 分希瓦的守护 → 33 分阿哈利姆神杖（38%）。对线期几乎不补给：只有 20% 补树、17% 补净化药水。
- **艾欧**：出门 树之祭祀 + 血腥榴弹 + 魔棒 + 铁树枝干，岗哨（61%）/ 力量手套（49%）/ 仙灵之火（55%）/ 回复戒指（25%）里挑；10 分钟内补眼（真眼 66%、假眼 69%）、树和血腥榴弹各一半人买 → 6.9 分魔杖、7.5 分灵魂之戒（89%）→ 18 分圣洁吊坠（87%）→ 26 分微光披风（44%）→ 后期坚韧球 19%、清莲宝珠 14%、Eul 13%。**梅肯斯姆只有 28%，同位置全部局是 74%**：拉席克自己出梅肯斯姆 / 卫士胫甲，艾欧就不重复出。
- **二选一（同经济差）**：慧夜对剑比散慧对剑 -2.8 ±3.1（20 分钟）/ -3.2 ±2.9（25 分钟），偏向散慧但不显著；卫士胫甲比圣化护服 +2.9 ±4.0，梅肯斯姆比圣化护服 +0.1 ±3.9，没区别；**28 分钟前出黑皇杖没出希瓦 vs 出希瓦没出黑皇杖：黑皇杖 -7.9 ±3.9**，对面难打 / 不难打两组都一样（-9.8 ±5.8 / -5.5 ±5.3），黑皇杖比血精石 -4.4 ±3.6；艾欧圣洁吊坠比梅肯斯姆 +3.1 ±4.6（20 分钟）、+0.7 ±4.9（25 分钟），没区别。黑皇杖那条有「被控得难受、打不顺才先出黑皇杖」的偏差，和第 69 节「对面有两个以上能穿的控制时黑皇杖 -3.8」方向一致，但不能当因果。

**谁出梅肯斯姆**（2026-11-09，`scripts/w_mek_fetch.py` 重新抓两人同队的 6331 局全场 10 人出装，`scripts/w_mek_an.py` 分析，第 71 节）：拉席克 1 + 艾欧 5、打满 20 分钟的 3905 局里，拉席克出 64%（中位 13.9 分）、艾欧出 29%（17.9 分），两人都出只有 6%，其余三个队友出梅肯 / 卫士胫甲只有 3%。拉席克出了，艾欧只有 9% 还出；拉席克没出，艾欧 65% 补上。**和对面阵容基本无关**：对面魔法伤害占比分三档，拉席克出的比例都是 62～64%；按对面 64 个英雄、队友 43 个英雄逐个看，校正后只有对面灰烬之灵时拉席克出得多（74%，z = +4.0）。**主要看拉席克自己的经济**：12 分钟经济每多 1000，拉席克出的概率 +5.2 个百分点（z = 5.6），低档 58%、高档 68%；拉席克没出梅肯时 25 分钟前多出慧夜对剑（68% 对 53%）、纷争面纱（68% 对 45%）、血精石（52% 对 30%）。25 分钟时两人都没梅肯的局，按 20 分钟经济差调整后胜率 59.8%，只有拉席克有 64.7%、只有艾欧有 62.7%。
**对线期艾欧出装变不变**（2026-11-09，`scripts/w_lane_an.py`，第 72 节）：同一批 3983 局，按 5 分钟「拉席克 + 艾欧 − 对面 3、4 号位」经济差分三档（劣 / 均 / 优，胜率 54% / 64% / 76%，艾欧 10 分钟前死 1.9 / 1.4 / 1.1 次）。**出门装三档几乎一样**；5~12 分钟的补给也只差几个点：劣势时补树 17%（优势 14%）、药膏 12%（10%）、恢复头巾 18%（12%），灵魂之戒晚约 1 分钟（8.1 对 6.8 分）；优势时多买诡计之雾（17% 对 12%），圣洁吊坠 15 分钟前出的比例 22%（劣势 7%）。**真正会变的是对面线上英雄**（34 个英雄 × 24 件 = 816 次比较，只列 |z| > 3.5）：对面有赏金猎人时 10 分钟内买显影之尘 69%（平时 8%）、岗哨 91%（平时 66%），树之祭祀少（31% 对 50%）；司夜刺客显影之尘 17%；帕吉 10 分钟内灵魂之戒 83%（平时 75%）、出门带药膏多一点；风行者灵魂之戒 63%。
## 小地图页面

```
python docs/research/io-leshrac/build_page.py                       # 生成 精灵老鹿小地图.html，双击打开
python docs/research/io-leshrac/build_page.py --minimap 小地图.png   # 改用自己截的小地图当底图（默认用高清小地图素材，--minimap none 不嵌）
```

- **页面功能**：「阵营」选全部时夜魇的局翻到天辉视角一起看，选天辉 / 夜魇时按真实地图朝向画（夜魇的我方在右上），右侧顶上显示这一边的局数、胜率、时长、对线、一塔时间。按 8 个阶段切换，看两人最常待的位置（小地图头像）、停留热区、两人参与的击杀、降临后击杀最集中的地方、对面每座建筑倒了多少、拉席克主推的塔。可以筛全部 / 赢的局 / 输的局。底部是出装、等级、倒塔的时间轴。
- **图标**：英雄头像、技能、装备读本机 `data/` 的缓存，缺的现从 Valve 官方 CDN 下（`sources/assets`）。
- **不进 git**：图片和生成的网页都不进 git，见 `.gitignore`。
- **换真实小地图底图，两种办法**：
  1. **嵌进页面**：`--minimap` 后面给一张方形、天辉在左下的整张小地图（世界坐标 ±9472 的正方形，同 `domain/camps.py` 的 `BOUND`）。也可以给整屏游戏截图，会按 `config.toml` 的 `minimap_x / minimap_y / minimap_size`（按 1080 高量）裁。
  2. **页面里导入**：打开页面后点「底图 → 导入游戏截图…」或 Ctrl+V 粘贴截图，裁切位置能在页面里改。截图只存在本机浏览器里。
- **裁切对过真实小地图**（2026-11-04，游戏电脑上）：拿助手之前在 Dota 里截的整屏截图（720 高、默认界面），`--minimap` 和页面里「导入游戏截图…」两条路裁出来的底图一样（相差不到 1 像素），把 28 个野点的游戏文件坐标画上去全都压在小地图的野点图标上，不用改那三个数。1080 高的截图也对得上（那张底部被 Windows 任务栏挡了一截，挡住的部分自然没有）。只试了默认界面：小地图放右边 / 加大小地图要改 `config.toml` 的三个数或页面里的裁切。
- **默认底图是高清小地图**（2026-11-04）：游戏截图里的小地图太小（720 高只有约 200 像素）、放大就糊，默认改用 Liquipedia Commons 上的 7.41 小地图游戏素材（1024×1024），第一次生成时下到 `data/icons/minimap_7.41.png`（不进 git），按 ±9472 的整张地图贴。拿英雄位置分布和它对过（相关系数 0.76，和最优拟合 0.763 差不多），塔、路、热区看着都在对的地方；**没拿游戏里的小地图逐点对过**。换版本要换 `build_page.py` 里的 `HD_MINIMAP_URL`。
- **塔位是估的**：建筑位置是按倒塔那一刻推塔英雄的站位估的，会偏向进攻方。
