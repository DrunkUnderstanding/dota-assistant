# 精灵老鹿：艾欧 + 拉席克组合研究（2026-11-04）

一次性研究，不进产品代码。数据：冠绝 / 超凡、7.41f、近 14 天天梯全英雄选择（OpenDota 统计 + STRATZ 已解析对局）。

## 结论

**强度**：两人同队 5466 局，胜率 63.4%。按两人各自强度推算，期望胜率是 54.9%，这对多出 8.5 个百分点，是艾欧所有队友里配合最好的。

**主流打法**：拉席克 1 号位 + 艾欧 5 号位，两人一起走优势路。能确定位置的 227 局里有 177 局是这样，胜率 63%。下面的数字都按这 177 局算。

**节奏（中位时间）**

| 时间 | 大概率在干什么 |
|---|---|
| 0~6 分钟 | 双人优势路对线，约 80% 时间贴在一起，线上一直在打架（前 10 分钟两人各死约 1.5 次）。奥术鞋之前基本不推塔。拉席克补刀比一般 1 号位多：5 分钟 23 刀，一般是 17 刀。 |
| 6~11 分钟 | 6.0 分钟奥术鞋到手后边打边推。拉席克 8.7、艾欧 9.3 分钟到 6 级，**10.8 分钟第一次降临**。对面全图第一座塔约 11 分钟倒。 |
| 11~15 分钟 | **11.3 分钟慧光**到手，推塔伤害翻倍。拉席克单推优势路上对面那座一塔（中位 14.4 分钟），开始刷自家主野区。看到机会就降临去中路或劣势路。 |
| 15~20 分钟 | 组合最强的一段：降临后 25 秒内我方有击杀的比例最高，72%。对面三座一塔基本都倒了，我方的中路和优势路一塔也常丢，本质是换塔。 |
| 20~30 分钟 | 21 分钟纷争面纱，25 分钟黑皇杖（赢的局 23.8 分钟、输的局 27.3 分钟）。赢的局对面二塔 25~26 分钟倒，三条路的二塔主要是拉席克推的。 |
| 30~35 分钟 | 上高地，最先、也最常推的是中路高地塔。赢的局基地中位 33.9 分钟倒。 |
| 35 分钟以后 | 降临后阵亡反而比击杀多，45 分钟以上的局胜率只有 46%。 |

**出装**

- **拉席克**：铁树枝干、仙灵之火、魔棒出门 → 3.3 分钟王者之戒 → 6.0 分钟奥术鞋 → 11.3 分钟慧光 → 二选一：14 分钟慧夜对剑或 17 分钟散慧对剑 → 梅肯斯姆，17 分钟合成卫士胫甲 → 21 分钟纷争面纱 → 25 分钟黑皇杖 → 26.5 分钟血精石 → 28 分钟希瓦的守护 → 32.6 分钟阿哈利姆神杖。
- **艾欧**：树之祭祀、血腥榴弹、岗哨守卫出门 → 6.2 分钟魔杖 → 7.6 分钟灵魂之戒 → 18 分钟圣洁吊坠 → 27 分钟微光披风。艾欧几乎不买鞋。

**对线**：优势 43%（其中碾压 11%）、均势 27%、劣势 31%。不管队友是谁，拉席克打 1 号位时是优势 43% / 均势 29% / 劣势 28%，几乎一样，说明这对的胜率主要不是对线赢出来的。均势的局胜率 68%，劣势的局还有 47%。

**推塔**：对面的建筑基本是拉席克推。我方英雄打对面建筑的伤害里，拉席克在优势路一塔占 80%，在二塔、高地占 60~67%，其中六到八成是技能伤害（恶魔敕令「对敌方单位和建筑造成纯粹伤害」）。艾欧只占 4~10%。优势路上对面那座一塔 18 分钟前倒的局胜率 71~86%，18 分钟后才倒只有 54%。

**难打的对面**：按克制数据，美杜莎、赏金猎人、远古冰魄、斯拉达、昆卡、圣堂刺客、不朽尸王克这对最狠。远古冰魄的冰晶爆轰会让目标「无法恢复生命值」，正好掐掉羁绊 / 过载的回血。

## 小地图页面

```
python docs/research/io-leshrac/build_page.py                       # 生成 精灵老鹿小地图.html，双击打开
python docs/research/io-leshrac/build_page.py --minimap 小地图.png   # 把自己截的小地图嵌进去当默认底图
```

- **页面功能**：按 8 个阶段切换，看两人最常待的位置（小地图头像）、停留热区、两人参与的击杀、降临后击杀最集中的地方、对面每座建筑倒了多少、拉席克主推的塔。可以筛全部 / 赢的局 / 输的局。底部是出装、等级、倒塔的时间轴。
- **图标**：英雄头像、技能、装备读本机 `data/` 的缓存，缺的现从 Valve 官方 CDN 下（`sources/assets`）。
- **不进 git**：图片和生成的网页都不进 git，见 `.gitignore`。
- **换真实小地图底图，两种办法**：
  1. **嵌进页面**：`--minimap` 后面给一张方形、天辉在左下的整张小地图（世界坐标 ±9472 的正方形，同 `domain/camps.py` 的 `BOUND`）。也可以给整屏游戏截图，会按 `config.toml` 的 `minimap_x / minimap_y / minimap_size`（按 1080 高量）裁。
  2. **页面里导入**：打开页面后点「底图 → 导入游戏截图…」或 Ctrl+V 粘贴截图，裁切位置能在页面里改。截图只存在本机浏览器里。
- **还没验证**：开发机没有真实的游戏内截图，裁切和真实小地图能不能对齐还没验证过。
- **塔位是估的**：建筑位置是按倒塔那一刻推塔英雄的站位估的，会偏向进攻方。

## 文件

| 文件 | 管什么 |
|---|---|
| `map_template.html` | 页面模板（`/*DATA*/` `/*ICONS*/` `/*MINIMAP*/` 三处由 `build_page.py` 填） |
| `viz_data.json` | 页面用的数据（177 局主流打法）：热区、击杀 / 阵亡坐标、每局倒塔时间和推塔伤害、估出的建筑位置、野点坐标 |
| `build_page.py` | 拼页面 |
| `scripts/` | 当时的研究脚本，按字母顺序大致是执行顺序，原样留档。路径写死成开发机的 `D:\xqs\tmp_io_lesh`，原始数据（STRATZ 对局约 45 MB）没进 git，要重跑得先改路径、重新拉 |

`scripts/` 里各脚本：

| 脚本 | 干什么 |
|---|---|
| `a_ids` | OpenDota explorer 找两人同队的局 |
| `d_fetch` | 拉 STRATZ 对局：出装、加点、技能释放、击杀、推塔 |
| `m_fetch` | 拉每 15 秒的位置 |
| `p_lane` | 拉对线结果 |
| `s_fetch` | 拉推塔伤害 |
| `e_an1`~`t_an` | 各项统计 |
| `n_an` | 地图分区，后面的脚本 `exec` 它 |
| `v_build` | 生成 `viz_data.json` |
