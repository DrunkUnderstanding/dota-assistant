# 7.42 的 1 / 2 / 3 号位怎么打更容易赢（2026-11-20）

玩家问「用实际对局分析 1、2、3 号位在这个版本改动下要用什么打法比较容易赢」。产出单文件网页 `data/mockups/7.42-1到3号位打法.html`（双击打开，约 40 KB）。

## 数据

- 7.42：OpenDota explorer 取上线（2026-11-18 21:00 UTC）后超凡～冠绝、天梯全英雄选择、≥15 分钟、10 人都在的全部对局（当时 7.1 万局），随机抽 1.5 万。
- 7.41f 对照：从 `docs/research/item-vs` 均匀抽好的 7.41f 编号（同样条件）里随机抽 1.5 万。
- STRATZ 每局取：击杀 / 助攻 / 死亡时间、每分钟身价 / 补刀 / 经验、站位采样（`locationReport`）、拿符、屯野、farm 来源、推塔（谁推的）、三路对线结果、出装。一次请求 20 局（25 局 STRATZ 回 400），约 1500 次请求、42 分钟。
- 能用的：7.42 13 783 局、7.41f 11 483 局（去掉没解析 / 位置不全 / 有人掉线放弃的；掉线 = 某人身价掉到最高时一半以下，或 15 分钟身价不到 1500）。

## 怎么算

- **时间段模型**：每个位置 × 时间段（0～10 / 10～20 / 20～30）× 版本：天辉赢没赢 ~ 天辉该位置减夜魇该位置的参与击杀、死亡、正补、站位靠前、亲手推塔（中单加拿符、1 号位加屯野）+ 时间段开始时两队经济差分档 + 双方该位置英雄。线性概率模型，系数 = 胜率百分点，HC1 稳健标准误。
- **翻盘模型**：15 分钟落后 ≥2000 的一方，15～25 分钟该位置减对面同位置 → 最后翻没翻盘（控制落后多少和英雄）。
- **经济差模型**：第 10 / 15 / 20 分钟五个位置和对面同位置的身价差一起放进去；**钱给谁**：第 20 分钟控制全队经济差，1 / 2 / 3 号位占全队比例差（每 5 个百分点）。
- 站位靠前 = 采样点离自家泉水的平均距离 ÷ 两泉水距离。`locationReport` 不管打多久都是约 68 个点，均匀铺满整局（第 i 个点 ≈ i × 时长 / 点数），不是每 30 秒一个。
- 相关不等于因果：控制不了玩家水平，单个系数偏大；两个版本同一个模型比，**系数的变化**更可信，结论主要看变化。约 60 次版本对比检验，按 5% 会有约 3 次碰巧。

### 「多参团了怎么少死」（2026-11-23 补）

- 一波团 = 按时间排的英雄死亡，和上一个隔 ≤20 秒、离这波中心 ≤25 格（STRATZ 坐标 1 格约 125 码）；只看 10～40 分钟。参了团 = 这波里自己死了或拿到击杀 / 助攻（只是在附近没拿到的算不上）。
- 被单抓 = 这波只有自己死、对面没死、身边最多一个队友；其余算团战里死。
- 开打时附近人数用站位采样（开打前 5 秒、离中心 ≤30 格），不受死没死影响；进场先后用自己在这波第一次出现在击杀记录里的时间。
- STRATZ 死亡事件的 `isTracked` / `isDieBack` 全是 0，`hasHealAvailable` 7.42 普遍偏高，没用。一次请求放 40 局回 400，35 局可以。

`conclusions.json` 是看完 `report.txt` 手写的结论文字（网页上的要点、实际对局例子、局限），重跑数据后要按新数字改。`probe.py` 查 STRATZ 字段名，`patch_text.py` 把中文版更新日志网页转成纯文本方便查改动。
