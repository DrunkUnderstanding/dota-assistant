# 7.42 胜率前 30 英雄的出装路线和胜率（2026-11-20）

玩家要「天梯胜率前 20 个英雄的出装路线」，之后改成前 30、每条路线标胜率、段位超凡以上。产出单文件网页 `data/mockups/7.42-胜率前30英雄出装.html`（双击打开，约 600 KB，图标都内嵌）。

## 数据

- **排名**：用胜率监控（`docs/research/patch-watch/`）攒的 STRATZ 分小时胜率，取超凡以上估计胜率（玩家要超凡以上；config 分段 7~8，也是胜率网页默认）前 30（`a_ids.py` 的 `TOP`）。
- **出装**：OpenDota explorer 取 7.42 上线（2026-11-18 21:00 UTC）后、平均段位超凡～冠绝、天梯全英雄选择、≥15 分钟的对局编号，每个英雄最多抽约 3000 局（冷门英雄先拿）；STRATZ 抓每局 10 人的购买记录、位置、输赢（字段和 `docs/research/item-vs` 一样，复用那边的抓取函数）。2026-11-20 一共抓 3.6 万局（分三次续抓，约 720 次请求、十几分钟），10 人都解析过、都有位置的 33726 局。

## 怎么算

- 每个英雄按 STRATZ 位置分开；某位置 ≥80 人次且占这个英雄 ≥15% 才列。
- 每件装备只算第一次购买。零件买了 90 秒内就合进成品的（攒零件 / 买齐自动合成，例如 7.42 鱼叉 = 回音战刃 + 魔龙枪）不算单独一步。
- **出门装**：开局 0 秒前买的东西，最常见的两套（整套一样才算一套）。
- **对线期**：<1800 金的合成小件，中位购买时间 ≤12 分、≥15% 的人买。
- **鞋**：每人第一双升级鞋。
- **核心路线**：≥30% 的人买的升级鞋和大件（≥1800 金），按中位购买时间排；之后合进路线里下一件的标成过渡件（虚线框）。
- **前三件大件**：每人买的第 1 / 2 / 3 件大件（不算鞋）各是什么。
- **看情况**：7%～30% 的人买的大件。
- **路线胜率**：路线 = 按购买顺序的前两件大件；最常见的前两件占一半以上、做完三件的人 ≥300 时按前三件分。只在做完这几件的人里比，≥40 人才列，按人数排。
  - 胜率 = 走这条的人赢的比例，± 是 95% 区间。
  - 同局势 = 赢没赢 − 做完那一分钟两队经济差应有的胜率（全部抓到的局现算的曲线，和 `docs/research/item-vs` 同一套），再减同英雄同位置全部人的平均。超出误差范围才标绿 / 红。
  - 前三件大件、鞋的每个选项也标了胜率和同局势。
  - 过渡件（夜叉 → 幻影斧）照购买顺序算，不按「之后有没有合成」去掉：那要看未来，会把没等到合成就输了的人分到另一条路线（试过，力丸「净魂之刃 → 夜叉」胜率 23%）。
- 排序都按购买比例 / 人数，不按胜率；网页上写明胜率只说明「走这条的人赢得多」，不完全等于「这么出更容易赢」。
