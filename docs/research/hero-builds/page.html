7.42 胜率前 30 英雄 · 出装路线和胜率

  • 胜率排名：超凡以上的估计胜率（上线前胜率作先验，用上线后实测更新，和「英雄胜率走势」页同一个算法）。
  • 出装：7.42 上线后超凡～冠绝天梯对局里，这个英雄在这个位置的人实际怎么出：百分比 = 买了这件的人占比，「分」= 买这件的中位时间。
  • 路线胜率：路线 = 按购买顺序的前两件大件（大多数人前两件都一样的英雄，按前三件分），只在做完这几件的人里比。胜率 = 走这条路线的人赢的比例（± 是 95% 误差范围）；做完大件的人多半在领先、本来就赢得多，所以同时看同局势：拿做完那一分钟两队经济差一样的局比，再和这个英雄别的出法比，高几个点 / 低几个点——这一列扣掉了「领先的人本来就赢」和英雄本身强弱，更接近路线本身的好坏。绿色 / 红色 = 差别超出误差范围，灰色 = 还分不出来。
  • 核心路线按中位购买时间排，只列 ≥30% 的人都买的鞋和大件（≥1800 金）；虚线框是之后会合进下一件的过渡件。前三件大件 = 每个人买的第 1 / 2 / 3 件大件（不算鞋）各是什么。
