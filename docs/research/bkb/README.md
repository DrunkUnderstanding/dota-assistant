# 黑皇杖是不是什么局面出都有用（2026-11-06）

一次性研究，不进产品代码。玩家原话：「BKB 这个装备，是不是什么局面出都有效果」。

## 数据

- 7.41f 超凡～冠绝天梯全英雄选择，不限英雄。OpenDota 在版本里均匀取 6 块 match_id，一共 57632 局，从中随机抽 2 万局，STRATZ 全部抓到（每人的出装时间、死亡、每分钟经济、位置）。
- 分析单位是核心（1 / 2 / 3 号位）的一局：92316 人次，127 个英雄，44% 整局出过黑皇杖。
- 这个版本黑皇杖 4050 金，核心出得晚：25 分钟前出了的 11.9%，30 分钟前 29.0%，35 分钟前 43.2%。所以比较时间点取 25 / 30 / 35 分钟。

## 方法（`scripts/c_an.py`）

- 只看打到 T 分钟的局，处理组是 T 分钟前出了黑皇杖。线性回归（稳健标准误），控制当时全队经济差（10 档 + 线性项）、自己的经济、之前死了几次、位置、阵营，以及**英雄固定效应**。所以比的是：同一个英雄、同样的经济下，钱花在黑皇杖上和花在别的装备上的差别。
- 结果只看胜率和之后 10 分钟的总死亡数（「被谁杀」在第 68 节已经证明不可靠）。
- 分组事先定好：对面控制技能多少、对面魔法伤害技能多少、对面**无视技能免疫的控制技能**有几个、当时经济落后 / 差不多 / 领先、自己几号位、近战 / 远程。每组都报黑皇杖的效果，以及最后一组减第一组的差。大约 60 次比较一起做多重比较校正，|z| > 3.34 才算数。
- 英雄的技能特征来自官方字段（`damage` = 魔法、`immunity` = 对敌方无视技能免疫、`dispellable` = 只能强驱散）和知识库标签（眩晕 / 妖术 / 沉默 / 缠绕定身）。这些**没有逐个核对**，有漏：虚空假面的时间结界、谜团的黑洞原文写的是「定住」/「拉向」，没被算成控制，所以「对面无视免疫的控制」一项漏了这几个大招。按这个规则算进去的有 21 个英雄：祸乱之源（魔爪）、帕吉（肢解）、斯拉达（深海重击）、术士（混乱之祭）、兽王（原始咆哮）、虚空假面（时间锁定）、发条技师（发射钩爪）、蝙蝠骑士（燃烧枷锁）、远古冰魄（冰晶爆轰）、裂魂人（巨力重击）、沉默术士（全领域静默）、独行德鲁伊、树精卫士、美杜莎、马格纳斯（两极反转）、巨牙海民（海象飞踢）、寒冬飞龙（寒冬诅咒）、天涯墨客、破晓辰星（星破天惊）、獸、凯。

## 结果

**1. 整体：黑皇杖能让你少死，但胜率没有更高。**

| T | 胜率 | 之后 10 分钟死亡 |
|---|---|---|
| 25 分钟 | -0.8 ±0.9 | **-0.06 ±0.04** |
| 30 分钟 | -0.9 ±0.7 | **-0.12 ±0.03** |
| 35 分钟 | -1.1 ±0.8 | **-0.06 ±0.04** |

少死是很确定的（30 分钟那行 z ≈ 8）。胜率稍微偏负，但这里有一个偏差没法排除：人往往是在被对面控得很难受的时候才去买黑皇杖，这种局本来就更难打（经济和之前的死亡数只能控制掉一部分）。所以**不能说「出了反而更容易输」**，只能说：平均下来，4050 金花在黑皇杖上，胜率没有比花在别的装备上高。

**2. 看局面：只有「对面能不能穿黑皇杖」这一项有明显区别。**

| 对面无视技能免疫的控制 | 25 分钟（胜率） | 30 分钟 | 35 分钟 | 25 分钟（之后 10 分钟死亡） |
|---|---|---|---|---|
| 0 个 | **+0.6 ±1.3** | -0.1 ±1.0 | -0.5 ±1.0 | **-0.11 ±0.05** |
| 1 个 | -1.3 ±1.4 | -1.1 ±1.1 | -1.4 ±1.1 | -0.06 ±0.06 |
| 2 个以上 | **-3.2 ±1.8** | -2.4 ±1.3 | -2.0 ±1.3 | +0.01 ±0.07 |
| 2 个以上 − 0 个 | **-3.8 ±2.1（z = -3.5，过校正）** | -2.2（z = -2.9） | -1.5（z = -1.9） | +0.11（z = 2.8） |

三个时间点方向一致，25 分钟那一格过了校正，死亡数也是同一个方向。这也和官方原文对得上：黑皇杖「获得减益免疫状态……持续时间内敌方技能的负面效果不会生效」，而这些技能的官方字段写的是对敌方无视技能免疫。**对面一个能穿的都没有时，出了黑皇杖胜率不亏、还少死；对面有两个以上能穿的，出了反而比花在别的装备上差 2～3 个百分点。**

**3. 其他几项都没有明显区别（都不过校正）**：
- 对面魔法伤害多：方向偏正（多 − 少：+1.8 / +1.6 / +0.8，z = 1.8 / 2.3 / 1.1），和「60% 魔法抗性」对得上，但还不够确定。
- 对面控制技能多少：没有区别，25 分钟还略偏负。这个分组规则比较粗（见上面说的漏项）。
- 当时经济落后 / 差不多 / 领先、自己 1 / 2 / 3 号位、近战 / 远程：都没有区别，差都在 ±1 个百分点以内。

## 结论

- **不是什么局面都有效**，它的作用主要是**保命**：出了以后之后 10 分钟大约少死 0.06～0.12 次，这一点在各种局面下都成立。
- 少死能不能转成胜率，**看对面能不能穿黑皇杖**：对面没有无视技能免疫的控制时值得出；对面有两个以上（比如斯拉达、马格纳斯、兽王、祸乱之源同时在），黑皇杖的价值明显下降，钱花在别的装备上更好。
- 经济领先还是落后、自己几号位、近战还是远程，都不改变黑皇杖值不值。
- 对产品的意义：「对面能穿 BKB 的控制有几个」可以作为出装提示的大数据依据（第 33 节要求的「大数据 + 本局」里的大数据那一半）。真要进出装逻辑，还得先把分组规则补全（时间结界、黑洞、决斗这类），再用另一批没用过的对局复核一次。
