# 同一时段做出来的装备，胜率高低是不是装备本身（2026-11-09）

一次性研究，产品代码没用它。起因：同行 gg-go-next 在「这个英雄、这个位置接下来 5 分钟大家常做的成装」旁边写胜率，玩家想加。

## 数据与做法

- 数据：黑皇杖研究（`docs/research/bkb/`）抓的 2 万局，7.41f 超凡～冠绝；每人每件成装（有合成配方且 ≥ 1000 金，或 ≥ 2000 金的非消耗品）第一次完成的时间，和当时自己队伍减对面的经济差。
- 10~45 分钟每 5 分钟一段，核心（1~3 号位）、辅助（4~5 号位）分开；每格只看 ≥ 300 次的装备。
- 「局势应有」：同一段、同一组里所有人每个整分钟的队伍经济差 → 胜率（分 20 档查表，不看买了什么）。某件装备的「局势应有」= 买它的人按买的那一分钟的经济差查到的胜率的平均。

## 结果

- 同一时段里，各装备原始胜率的高低有 **91%** 是买的时候领先或落后造成的（原始胜率差对「局势应有」差的回归斜率 1.01）。
- 扣掉局势后，跨装备还剩标准差 2.2 个百分点，其中光抽样噪声就有 1.8；去掉噪声后真实差别约 1.2 个百分点，而且还混着英雄和玩家水平。
- 例：15~20 分钟核心的狂战斧原始胜率 38.2%，局势应有 37.9%（落后的人才这时候还在出）；20~25 分钟黑皇杖 59.2%，局势应有 58.6%；点金手几乎每格扣掉局势后都是 −2~−3。

## 结论

出装旁边不显示原始胜率：显示出来，基本是在告诉你「买这件的人当时领不领先」。扣掉局势后的差别太小、太噪，也不值得显示。
