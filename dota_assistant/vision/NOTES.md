## 19. 禁用识别：选人网格的红斜线（2026-10-23，`grid.py` + `gamefiles.py`）

玩家需求（原话）：「我希望你能够识别选人阶段被ban掉的角色，这个你能测试去做做看吗」。

**做法**（第 7 节第 2 项的调研结论：聊天框装不下全部禁用，只能看网格）：
1. **找格子**：网格背景是平滑的蓝灰渐变，格子是有纹理的矩形；同一行底边对齐、大小一样。变暗的格子会和背景粘连，用左右 / 上下间距补出来。不写死位置（玩家用自定义布局）。
2. **认格子是谁**：格子里显示的是游戏资源里的 `panorama/images/heroes/selection/npc_dota_hero_<key>_png.vtex_c`。
   - 先试过 Valve 网站的竖版图（`_vert.jpg`）：是老美术，127 格只有约 88 格靠得住（宙斯、圣堂、风行等对不上）。
   - 改成 `gamefiles.py` 从 `game/dota/pak01_dir.vpk` 直接导出（只读磁盘上的静态图片文件，不碰游戏进程 / 内存；`start` 时自动做，vpk 修改时间变了才重导）。
     118 个英雄的资源里嵌着 PNG；9 个新英雄（森海飞霞、虚无之灵、电炎绝手、百戏大王、破晓辰星、玛西、獸、琼英碧灵、朗戈）是 YCoCg 编码的 DXT5，自己解。
   - 模板宽 ≈ 格子宽 ×1.21~1.26，先用几个格子估缩放再全网格匹配，每个英雄只出现一次（贪心）。机器人局干净画面：127 格全认出，最低分 0.70，第二名都低得多。
   - 建图约 4 秒，在后台线程做；同一布局存在 `data/grid_map.json`（按画面大小 + 格子位置区分，最多 6 种），以后每帧只要 0.06 秒。
3. **判断禁用**：格子中部灰度标准差 < 18（变暗）且右上 → 左下直线上比两侧红 ≥ 12（红斜线）。只变暗没斜线 = 已经被选走（记在 `BanWatcher.taken`，现在只进日志）。
4. **什么时候建图**：GSI 处在 `HERO_SELECTION`、格子位置连续两帧一样（刚进选人有过场动画，实测第一帧建出过 134 格的错图）。
   优先用「干净画面」（变暗的格子 ≤ 3 个，选人刚开始还没禁用时）；只能在已有禁用的画面上建时先凑合用，变暗格子要用灰度 + 遮掉斜线去认，
   黑乎乎的英雄会认错（实测把司夜刺客认成朗戈，修了「行底对齐」后对了，但不保证），以后遇到干净画面会换掉。
5. 禁用整局累加，进新一局选人（GSI 进 `HERO_SELECTION`）或「清空」时清掉；进推荐的「禁用」列表（候选里去掉），叠加层多一行「禁」（灰头像 + 红斜线）。

## 56. 游戏画面野点框刷新加快 + 试玩模式空格子不算死 + 野点标记日志不重复（2026-11-03）

玩家（原话，试玩里看拉野 / 屯野框时）：「这个叠加层有点延迟，感觉怪怪的，能否把这个刷新的间隔搞快一点」；「bug 正常修」。

**刷新加快**：
| | 以前 | 现在 |
|---|---|---|
| 认镜头（`world.FRAME`） | 0.1 秒一帧（10 帧 / 秒） | 0.04 秒一帧（约 25 帧 / 秒） |
| 截 Dota 窗口（`capture.WindowGrabber.grab`） | 约 27 毫秒 | 约 16 毫秒：去第 4 通道从 `np.ascontiguousarray` 换成 `cv2.cvtColor`（10 毫秒 → 1 毫秒），全黑检查先看稀疏的点；截出来的像素一样 |

CPU（Ryzen 5 9500F 实测，只在有框时）：10 帧 / 秒时一个核的 32% → 现在 25 帧 / 秒一个核的 48%（12 线程里约 4%）。没量对 Dota 帧数的影响。
**按镜头速度往前推**（同日，玩家试完上面这版：「镜头移动比较快的时候还是会有点跟不上」）：world 线程留最近三帧认到的镜头位置，
`world.camera_velocity` 算拉镜头的速度——两段速度对得上（差 ≤ 40%）、速度在 300~10000 码 / 秒里才算，刚开始拉 / 刚停 / 点小地图跳过去 / 认血条抖动 / 丢了帧都给 0；
`world_view` 每次被拉时把镜头位置推到「现在 + 0.03 秒」（页面拿到后到画上屏幕大概的时间），最多推 0.12 秒。页面有框时改成 20 毫秒拉一次（每次都推到那一刻，框走得顺）。
代价：镜头突然停下时框会往前冲一下、下一帧（≤ 0.04 秒）回来。几个数（`PREDICT` / `DISPLAY_LAG` / `CAM_SPEED` / `CAM_AGREE`）都是实现假设，没在真游戏拉镜头时量过（不能模拟键鼠，要玩家拉）。
